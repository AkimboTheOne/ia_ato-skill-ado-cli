# Exports

## Output formats

- Markdown for human-readable artifacts.
- JSON manifest for machine-readable traceability.

## Export commands

- `work-item export`
- `wiki export`
- `repo export`
- `pr export`
- `commit export`
- `bundle export`

## Templates

- Built-in templates under `templates/markdown`.
- Custom template path via `--template` (work-item/wiki exports).
