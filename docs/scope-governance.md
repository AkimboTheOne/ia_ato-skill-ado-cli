# Scope Governance

## In scope (v0.2)

- ADO Cloud read operations over Work Items, Wiki, Repos, PRs and Commits.
- Controlled Work Item write operations.
- Export and manifests for machine consumption.

## Out of scope (v0.2)

- Wiki write.
- Repo write.
- Bulk mutating workflows.
- ADO Server on-prem support.
- Full MCP bridge runtime.
